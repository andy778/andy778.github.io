# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report it via [GitHub's private vulnerability reporting](https://github.com/andy778/andy778.github.io/security/advisories/new).

I will acknowledge your report within 48 hours and aim to release a fix within 14 days for confirmed vulnerabilities.

## Supported Versions

This is a personal static site. Only the latest version on `main` is actively maintained.
